# SA 測試案例與驗收條件（摘要）

## 登入 / 登出 / Token
- 成功登入：有效帳密，回 access/refresh；稽核記錄；前端進入首頁。
- 失敗登入：錯誤帳密，增加計數，回非敏感錯誤，稽核記錄。
- 鎖定：連續 5 次失敗，鎖 15 分鐘，鎖定期間拒絕登入並提示剩餘時間。
- 閒置逾時：30 分鐘無操作，自動登出；後端拒絕逾時 token。
- 登出/撤銷：同時失效 access/refresh，跨裝置阻擋後續請求，稽核記錄。
- 刷新：有效 refresh 可換新 access（可滾動 refresh），撤銷或過期返回 401。

## RBAC / 授權
- 有權存取：授權資源返回成功。
- 無權存取：返回 403，稽核記錄原因，訊息不洩漏細節。
- 角色/權限變更：新請求套用新權限；如撤銷/修改角色，先前無權的請求仍被拒絕。
- 多裝置：撤銷單一會話後，該會話後續請求被拒絕；其他會話仍可用（除非全撤）。

## 稽核
- 登入/登出/拒絕/角色或權限變更均被記錄，欄位含 user、resource、action、decision、IP、UA、時間。
- 稽核查詢可依 user/resource/action/decision/time 篩選。

## 資料與安全
- 密碼雜湊儲存；初始管理員需強制改密。
- CORS/HTTPS 設定符合政策（至少允許受控來源；預留 HTTPS）。
- 日誌遮罩敏感資訊；錯誤訊息不洩漏內部細節。

## 前端 UX
- Login 頁：顯示錯誤與鎖定提示；Loading 狀態。
- Route Guard：未登入導向登入；權限不足導向 403。
- 錯誤頁：403/404 顯示清楚並可返回/登出。
